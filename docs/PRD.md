# 台球联盟管理系统 - 产品需求文档（PRD）

> 版本：v1.0
> 日期：2026-04-27

---

## 一、产品概述

### 1.1 产品定位

面向台球联盟管理者，提供一站式台球厅、助教、比赛的数字化管理工具。

### 1.2 目标用户

| 用户角色 | 使用场景 | 核心诉求 |
|----------|----------|----------|
| 联盟管理员 | 办公室 + 现场 | 全局掌控、数据分析 |
| 台球厅管理员 | 球厅现场 | 日常运营、比赛执行 |

### 1.3 产品目标

1. 实现台球厅、助教、比赛的统一数字化管理
2. 支持办公室管理 + 比赛现场移动端使用
3. 提供数据报表辅助决策

## 二、功能需求

### 2.1 台球厅管理模块

#### 2.1.1 台球厅基础信息

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 列表查看 | 支持按名称/状态筛选、搜索 | P0 |
| 新增台球厅 | 录入名称、地址、联系电话、营业时间 | P0 |
| 编辑台球厅 | 修改基本信息 | P0 |
| 启用/停用 | 状态管理 | P0 |
| 删除台球厅 | 软删除，保留历史数据 | P1 |

#### 2.1.2 场地管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 球台管理 | 维护球台数量、类型（斯诺克/美式落袋/中式等） | P1 |
| 场地布局 | 球台位置可视化（可选） | P2 |

---

### 2.2 助教管理模块

#### 2.2.1 助教基础信息

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 列表查看 | 按台球厅筛选、支持搜索 | P0 |
| 新增助教 | 录入姓名、电话、所属球厅、擅长球种、等级 | P0 |
| 编辑助教 | 修改基本信息 | P0 |
| 在职/离职 | 状态管理 | P0 |
| 删除助教 | 软删除 | P1 |

#### 2.2.2 助教档案

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 详细信息 | 查看完整档案、关联比赛记录 | P1 |
| 绩效标签 | 标注优秀助教（可选） | P2 |

---

### 2.3 比赛管理模块

#### 2.3.1 比赛创建

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 基本信息 | 名称、主办球厅、时间、赛制 | P0 |
| 赛制选择 | 单败淘汰、双败淘汰、循环赛 | P0 |
| 参赛人员 | 选手报名、助教参与（选手/裁判） | P0 |
| 报名管理 | 选手报名、资格审核 | P1 |

#### 2.3.2 赛程管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 自动生成 | 根据赛制、参赛人数自动生成对阵图 | P1 |
| 手动调整 | 支持调整对阵、种子设置 | P1 |
| 赛程展示 | 清晰展示各轮次、时间、场地 | P1 |

#### 2.3.3 比赛执行

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 成绩录入 | 录入每场比赛结果 | P0 |
| 实时排名 | 比赛过程中实时更新排名 | P1 |
| 状态流转 | 筹备中 → 报名中 → 进行中 → 已结束 | P0 |

#### 2.3.4 比赛成果

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 名次展示 | 最终排名、冠亚季军 | P0 |
| 成绩存档 | 完整比赛记录、历史查询 | P0 |

---

### 2.4 奖金与积分模块

#### 2.4.1 奖金管理

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 奖金规则 | 设置奖金分配比例（冠军/亚军/季军等） | P1 |
| 奖金计算 | 根据规则自动计算奖金金额 | P1 |
| 奖金发放 | 标记已发放状态 | P2 |

#### 2.4.2 积分系统

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 积分规则 | 参赛获得基础分、获奖额外加分 | P1 |
| 积分排行 | 按年度/总积分排名 | P1 |
| 段位称号 | 根据积分划分段位（新手/业余/专业等） | P2 |

---

### 2.5 报表分析模块

#### 2.5.1 数据看板

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 概览仪表盘 | 球厅数量、助教人数、比赛场次、参赛人次 | P1 |
| 趋势图表 | 比赛场次趋势、参赛人数趋势 | P1 |

#### 2.5.2 统计分析

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 营收统计 | 各球厅比赛收入（若需收费） | P2 |
| 助教绩效 | 助教参赛次数、获奖统计 | P1 |
| 比赛历史 | 各球厅历史比赛查询 | P1 |

## 三、非功能需求

### 3.1 响应式设计

- 桌面端：后台管理、办公室场景
- 移动端：比赛现场成绩录入、报名管理

### 3.2 权限控制

- 联盟管理员：全局数据访问
- 球厅管理员：仅本球厅数据

### 3.3 数据安全

- 操作日志记录
- 敏感数据脱敏

---

## 四、优先级汇总

| 阶段 | 功能 | 优先级 |
|------|------|--------|
| **P0 - 基础核心** | 台球厅 CRUD、助教 CRUD、比赛基本流程 | 当下必须 |
| **P1 - 核心增强** | 赛程生成、报名管理、成绩录入、报表 | 重要功能 |
| **P2 - 高级特性** | 奖金积分、场地可视化、段位系统 | 优化体验 |

