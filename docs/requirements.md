# 台球联盟管理系统 - 需求文档

## 1. 项目概述

**项目名称：** 台球联盟管理系统

**项目目标：** 建立一个台球联盟管理平台，实现对台球厅、台球厅助教以及台球厅比赛的维护与管理。

## 2. 功能需求

### 2.1 维护台球厅

- **基本信息管理**：台球厅名称、地址、联系电话、营业时间
- **场地信息管理**：球台数量、球台类型（斯诺克、美式落袋等）
- **状态管理**：启用/停用台球厅

### 2.2 维护台球厅助教

- **基本信息管理**：助教姓名、联系电话、所属台球厅
- **专业技能**：擅长球种、等级/段位
- **状态管理**：在职/离职

### 2.3 建立台球厅比赛

- **比赛基本信息**：比赛名称、主办台球厅、时间、赛制
- **参赛人员**：参赛选手、助教（可作为选手或裁判）
- **比赛结果**：记录名次、成绩
- **比赛状态**：筹备中、报名中、进行中、已结束
